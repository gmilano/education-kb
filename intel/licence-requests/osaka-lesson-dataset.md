## Suggested issue body

Hello, and thank you for publishing this work.

I maintain a curated index of open education-AI projects used to identify starting points for
education engagements. Your repository is, as far as our survey has found, **the most useful
Japan-origin lesson-data artefact of its kind that we have come across**, and we would like to be
able to recommend and build on it.

At the moment the repository does not appear to include a licence file — we enumerated the full tree
(`26` files) and found no `LICENSE`, `COPYING` or equivalent. Without an explicit licence, default
copyright applies, which means others cannot legally reuse, modify or redistribute the work even
when you would be happy for them to.

If you are willing, adding a licence would let the work be used. A permissive licence such as
**MIT** or **Apache-2.0** allows the widest reuse; **CC-BY-4.0** is often the better fit for a
dataset specifically. GitHub can add one for you: *Add file → Create new file → type `LICENSE` →
'Choose a license template'*.

No obligation at all, and thank you either way for making the work public.
