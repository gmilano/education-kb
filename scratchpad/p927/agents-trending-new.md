  says the operative licence is recorded **per record, inside the JSON**. 🔵 That per-record claim is

  project's claim and not as an independent byte-read.

🔵 **`927-G1` — gate, extending `904-G1`.** `904-G1` said: when the payload is data or content,
probe the **payload directory** before recording SPDX. `p927` raises it one level: **the payload can
be a different repository, and a repository with no licence file is not necessarily unlicensed.**
Before writing a content-bearing row: (a) find where the content actually lives, (b) probe *that*
address, (c) if it has no licence file, **read its README for a prose grant**, and (d) if the grant

**fifth** licence axis in this base, after path-dependence (`T24`), content-vs-code (`T25`),
split-root (`904-G1`) and the mark (`T27`).

usable — but attribution is **per hint, per scaffold and per problem**, which is a delivery
obligation a studio has to build for, not a line in a licence table. The row in `agents/top.md` is
